# 来源与许可记录

| 内容 | 来源 | 本仓库处理 |
|---|---|---|
| 题目标题与 ID | Playground CLI task list，2026-10-20 | 保存选题索引和来源链接 |
| 题目要求与评分方式 | 每题官方题面/API | 读题后逐题记录，当前未复制题面 |

| 第三方数据/论文/代码 | 各自发布者 | 保留原许可；未知许可时给来源，不再分发 |
| 原生 agent session | 本地运行环境 | 私有保存，用于必要的比赛提交，不公开整段会话 |

尚未核实每道候选题的数据许可、具体赛事公开限制与预期产物；这些在实际解题建档时填写。仓库初始化不包含第三方题包或答案。
